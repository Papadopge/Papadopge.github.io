How I approach a project

A structured process from scope to release confidence.

01 / ASSESS

Understand the product

Review the application, existing tests, architecture, current QA process and the highest-risk areas before deciding what to automate.

02 / PLAN

Define the testing scope

Prioritise scenarios, regression coverage and automation opportunities based on business impact and release needs.

03 / BUILD

Execute & automate

Perform the required testing while building or improving automated checks that provide repeatable value to the team.

04 / REPORT

Make quality visible

Communicate defects, coverage, findings, risks and progress clearly so the team can make informed release decisions.
