How I approach a project

A structured process from requirements to reliable delivery.

01 / ASSESS

Understand the product

Review the application, requirements, existing tests, architecture and current QA process before defining the testing strategy.

02 / PLAN

Define the testing scope

Prioritise test scenarios, regression coverage and automation opportunities based on business impact and release risk.

03 / BUILD

Execute & automate

Perform manual testing while building or improving automated checks that provide repeatable value to the development team.

04 / REPORT

Make quality visible

Clearly communicate defects, test coverage, risks, findings and progress so the team can make informed release decisions.
